# Antigravity Remote Clients (Desktop & Mobile)

Este repositorio contiene dos clientes dedicados para conectarte a la función **Remote Control** de Google Antigravity:

1. **`electron-app/`**: Aplicación de escritorio multiplataforma (Linux, Windows, macOS) construida con Electron.
2. **`android-app/`**: Proyecto de aplicación móvil para Android listo para compilar en un archivo `.apk`.

---

## ⚡ ¿Cómo obtener el enlace de conexión?
1. En la aplicación de Antigravity en tu computadora principal, ve a la sección de **Remote Control**.
2. Asegúrate de tener activado el interruptor **Enable Remote Control**.
3. Haz clic en **"copy link"**.
4. Pega ese enlace en la app (ya sea en la de escritorio o en la de Android). Ambas guardan el enlace para que solo tengas que ponerlo una vez.
